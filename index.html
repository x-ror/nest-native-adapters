nest-native-adapters

Run NestJS on node:http or Bun.serve — without Express or Fastify.
Get startedView on GitHub

Only the HTTP layer changes

Modules, DI, decorators, guards, pipes, interceptors, filters and the lifecycle are still Nest’s own.

Node.js and Bun

NodeHttpAdapter on node:http (Node.js 22+), BunHttpAdapter on Bun.serve (Bun 1.4+).

Express-compatible behavior

CORS, cookies, static files, uploads, versioning, SSE, views and trusted proxies behave like Nest’s Express adapter.

Nest 10, 11 and 12

Tested against NestJS 10, 11 and 12 on both runtimes.
